## 2. 📐 Definition & Mathematical Formulation of Evaluation Metrics

### 1. Categorical Accuracy
$$\text{Accuracy} = \frac{\text{Number of Correct Predictions}}{\text{Total Predictions}} = \frac{\sum_{i=1}^C \text{TP}_i}{N}$$
- **Interpretation:** The overall proportion of test leaf images correctly classified across all target conditions.

### 2. Precision (Positive Predictive Value)
$$\text{Precision}_c = \frac{\text{TP}_c}{\text{TP}_c + \text{FP}_c}$$
- **Interpretation:** When the model diagnoses a leaf as having *Tomato Late Blight*, Precision measures the probability that the leaf actually has *Late Blight* rather than being a false alarm. High precision prevents unnecessary application of expensive chemical fungicides.

### 3. Recall (Sensitivity / True Positive Rate)
$$\text{Recall}_c = \frac{\text{TP}_c}{\text{TP}_c + \text{FN}_c}$$
- **Interpretation:** The proportion of actual diseased leaves that were successfully detected by the model. In agriculture, **Recall is the most critical metric**, because missing a genuine *Late Blight* infection (False Negative) can lead to catastrophic farm-wide crop devastation within days.

### 4. F1-Score (Harmonic Mean)
$$\text{F1-Score}_c = 2 \times \frac{\text{Precision}_c \times \text{Recall}_c}{\text{Precision}_c + \text{Recall}_c}$$
- **Interpretation:** Balances Precision and Recall into a single metric, especially useful when class distributions have slight imbalances.

### 5. Confusion Matrix ($C_{i,j}$)
- A $K \times K$ matrix where element $C_{i,j}$ represents the count of images known to belong to true class $i$ that were predicted as class $j$. Diagonal elements represent correct classifications; off-diagonal elements expose specific pathogen confusion patterns.
