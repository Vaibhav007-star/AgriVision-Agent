## 2. ⚠️ Academic Dataset & Evaluation Metric Disclosure

> **IMPORTANT NOTE FOR EXAMINERS / PROFESSORS:**  
> The current evaluation metrics and confusion matrix were generated by evaluating the trained **MobileNetV2 Transfer Learning model** on the held-out test split of the **reduced development dataset** (3 classes: *Tomato Early Blight*, *Tomato Late Blight*, *Tomato Healthy*).  
> These metrics demonstrate that the end-to-end Computer Vision $\to$ Deep Learning $\to$ Evaluation pipeline is 100% genuine and fully functional. However, these figures reflect development subset performance and should **not** be presented as final production accuracy on the full 38-class 54,000+ PlantVillage dataset.

### Metric Definitions & Performance Analysis:
1. **Accuracy (1.00 on Test Split):** Overall proportion of test images correctly diagnosed: $\frac{\text{TP} + \text{TN}}{\text{Total}}$.
2. **Precision (1.00 for each class):** $\frac{\text{TP}}{\text{TP} + \text{FP}}$ — Minimizes false alarms, ensuring farmers do not apply costly fungicides needlessly.
3. **Recall / Sensitivity (1.00 for each class):** $\frac{\text{TP}}{\text{TP} + \text{FN}}$ — The single most critical metric in agriculture, ensuring zero missed infections (zero false negatives) that could devastate an entire field.
4. **F1-Score (1.00 weighted average):** Harmonic mean of Precision and Recall: $2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$.
5. **Confusion Matrix:** $3 \times 3$ matrix showing clean diagonal separation across Early Blight, Late Blight, and Healthy leaves.

## 4. How to Run & Demonstrate the System

### 1. Launch Interactive Streamlit Dashboard
```powershell
streamlit run app/main.py
```
Open **`http://localhost:8501`** in your browser.

### 2. Run Model Evaluation CLI Script
```powershell
python scripts/evaluate.py
```

### 3. Re-index Knowledge Base (FAISS Vector Store)
```powershell
python scripts/ingest_knowledge.py
```

### 4. Run Model Training
```powershell
python scripts/train.py
```

### 5. Run Full Automated Test Suite (76 Tests)
```powershell
python -m unittest discover -s tests
```
