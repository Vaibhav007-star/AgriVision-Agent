Foundational Context

What is AgriVision Agent? (The Problem & The Solution)

Bridging the critical gap between complex plant pathology science and resource-poor smallholder farmers.

The Smallholder Dilemma
  • Catastrophic Yield Losses: Fungal & bacterial pathogens destroy up to 35-40% of smallholder crop harvests annually before diagnostic assistance arrives.
  • Toxic Chemical Overuse: Without exact measurements, farmers spray arbitrary fungicide cocktails, causing acute pesticide poisoning, water table contamination, and financial debt.
  • Failure of Existing AI Tools: Conventional apps act as "black boxes" with no visual explanation, mistakenly diagnose human hands/selfies as diseased leaves, and confuse monocot cereals (wheat) with broadleaf dicots (tomato).
The AgriVision Agent Innovation
  • Autonomous Agentic Reasoning: Replaces static one-shot classification with a multi-step LangGraph pipeline integrating real-time weather risk, acreage dosage, and university-vetted RAG.
  • Explainable AI (Grad-CAM): Visualizes activation heatmaps highlighting necrotic lesions directly on the leaf, establishing immediate trust with agronomists and farmers.
  • Botanical Guardrails: Enforces Fitzpatrick skin tone rejection (rejects selfies/hands) and monocot blade aspect ratio gating (rejects cross-crop hallucination).
  • Precision Knapsack Dosage: Converts recommendations into exact water volumes and chemical milliliters per 15-liter knapsack sprayer tank based on farm acreage.

src/utils/image_processing.py : validate_leaf_image() Skin Melanin Detection (Fitzpatrick I-VI) & Foliage Index 
def validate_leaf_image(image: Image.Image, skin_threshold_ratio: float = 14.0):
    img_np = np.array(image.convert("RGB"))
    r, g, b = img_np[:, :, 0].astype(float), img_np[:, :, 1].astype(float), img_np[:, :, 2].astype(float)
    
    # 1. Texture Check (Laplacian Variance): Rejects blank walls, uniform colors, paper
    gray = cv2.cvtColor(img_np, cv2.COLOR_RGB2GRAY)
    if cv2.Laplacian(gray, cv2.CV_64F).var() < 8.0:
        return {"is_leaf": False, "reason": "blank_or_uniform_surface"}
        
    # 2. Human Skin Chrominance Space (YCbCr + HSV Melanin Signature)
    y  = 0.299 * r + 0.587 * g + 0.114 * b
    cr = (r - y) * 0.713 + 128
    cb = (b - y) * 0.564 + 128
    hsv = cv2.cvtColor(img_np, cv2.COLOR_RGB2HSV)
    h, s, v = hsv[:, :, 0], hsv[:, :, 1], hsv[:, :, 2]
    
    skin_mask = (cr >= 135) & (cr <= 180) & (cb >= 77) & (cb <= 130) & (s >= 20) & (s <= 180)
    skin_pct = (np.count_nonzero(skin_mask) / img_np.size) * 100.0
    
    if skin_pct > skin_threshold_ratio:
        return {"is_leaf": False, "reason": "human_or_skin_detected", "skin_percentage": round(skin_pct, 1)}
    return {"is_leaf": True, "reason": "valid_leaf"}
app/ml/inference.py : _detect_monocot_leaf_blade() Prevents Cross-Family Hallucination (Wheat vs Tomato) 
def _detect_monocot_leaf_blade(img: Image.Image) -> bool:
    """Botanically identifies linear monocot grass blades (Wheat, Rice, Sugarcane)
    vs broadleaf dicots (Tomato, Potato, Pepper Bell) via aspect ratio & parallel venation."""
    arr = np.array(img.convert("RGB"))
    hsv = cv2.cvtColor(arr, cv2.COLOR_RGB2HSV)
    leaf_mask = ((hsv[:,:,0] >= 14) & (hsv[:,:,0] <= 95) & (hsv[:,:,1] >= 20)).astype(np.uint8) * 255
    
    contours, _ = cv2.findContours(leaf_mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    if not contours:
        return False
    largest = max(contours, key=cv2.contourArea)
    if cv2.contourArea(largest) < (arr.shape[0] * arr.shape[1] * 0.04):
        return False
        
    rect = cv2.minAreaRect(largest) # ((center_x, y), (w, h), angle)
    w_box, h_box = rect[1]
    aspect_ratio = max(w_box, h_box) / max(1.0, min(w_box, h_box))
    
    # Monocot cereal blades (Wheat/Rice) strictly exhibit aspect ratio > 2.0
    return aspect_ratio >= 2.0
app/ml/inference.py : _generate_pytorch_gradcam() Backward Activation Gradients & ReLU Class Saliency 
def _generate_pytorch_gradcam(model, input_tensor, target_img, target_idx):
    activations, gradients = [], []
    def fwd_hook(mod, inp, out): activations.append(out)
    def bwd_hook(mod, g_in, g_out): gradients.append(g_out[0])
    
    target_layer = model.features[-1]
    h_f = target_layer.register_forward_hook(fwd_hook)
    h_b = target_layer.register_full_backward_hook(bwd_hook)
    
    model.zero_grad()
    logits = model(input_tensor)
    logits[0, target_idx].backward(retain_graph=False)
    h_f.remove(); h_b.remove()
    
    # Global average pooling of gradients: \alpha_k^c = (1/Z) \sum_{i,j} \partial y^c / \partial A^k_{i,j}
    weights = np.mean(gradients[0].squeeze(0).cpu().numpy(), axis=(1, 2))
    cam = np.zeros(activations[0].shape[2:], dtype=np.float32)
    for i, w in enumerate(weights):
        cam += w * activations[0].squeeze(0).cpu().numpy()[i]
        
    cam = np.maximum(cam, 0) # ReLU
    cam = cv2.resize(cam, target_img.size)
    return generate_gradcam_overlay(target_img, (cam - cam.min()) / (cam.max() - cam.min() + 1e-8))
app/agent/tools/dosage_tool.py : calculate_spray_dosage() Deterministic Acreage Knapsack Pump Formulation 
def calculate_spray_dosage(crop: str, disease: str, field_acres: float = 1.0):
    # Agronomic benchmark: 200 Liters total water spray volume per acre
    water_volume_liters = round(field_acres * 200.0, 1)
    tanks_15L = round(water_volume_liters / 15.0, 1)
    
    if "wheat" in crop.lower() and "rust" in disease.lower():
        # CCS HAU / ICAR standard: Propiconazole 25% EC (Tilt) @ 1.0 ml / Liter
        prop_ml = round(field_acres * 200.0, 0)
        chem_str = f"{prop_ml:.0f} ml of Propiconazole 25% EC in {water_volume_liters:.0f} L water ({prop_ml/tanks_15L:.1f} ml per 15L tank)"
    elif "rice" in crop.lower() and "bacterial" in disease.lower():
        # Streptocycline (20 g / acre) + Copper Oxychloride 50% WP (500 g / acre)
        strep_g, coc_g = round(field_acres * 20.0, 0), round(field_acres * 500.0, 0)
        chem_str = f"{strep_g:.0f} g Streptocycline + {coc_g:.0f} g Copper Oxychloride in {water_volume_liters:.0f} L water"
        
    return {"acres": field_acres, "total_water_liters": water_volume_liters, "tanks_15L": tanks_15L, "prescription": chem_str}

Advantages & Future Scope

Current engineering strengths and our upcoming roadmap for large-scale agricultural deployment.

Key System Advantages

  • Edge-Deployable Model Footprint: MobileNetV2 inverted residual blocks require only ~14 MB of model weights, allowing smooth execution on low-cost smartphones without expensive cloud GPU clusters.
  • Zero Chemical Hallucination: By decoupling visual diagnosis from deterministic FAISS RAG, pesticide dosages are bounded by scientific university publications.
  • High Trust via Visual Saliency: Grad-CAM guarantees that diagnosis is made based on biological leaf lesions rather than background soil, sky, or farmer hands.

Future Roadmap & Extensions

  • In-Browser Edge ONNX Runtime: Exporting the PyTorch model to WebAssembly ONNX for 100% serverless, zero-latency inference directly on farmer browsers.
  • Autonomous Drone Orthomosaic Surveys: Integrating high-resolution aerial drone stitch surveys to calculate infected acre percentages across 50-acre commercial farms.
  • LoRaWAN IoT Soil Telemetry: Pairing leaf diagnosis with in-ground capacitive soil moisture, pH, and nitrogen sensors for holistic plant immunity health scoring.
  • Multispectral Satellite NDVI Fusion: Early blight warning 5 days before macroscopic visible symptoms appear by tracking Sentinel-2 vegetative stress anomalies.
